Limitations: Momentary button or sensor pulses shorter than the polling interval (~500 ms) may not appear on this dashboard — the OEE recorder is subject to the same limitation, so a very quick part passage may be missed entirely. OEE figures are not computed here: each line PC runs a standalone recorder (python -m app.recorder) that persists OEE history to that line's local oee PostgreSQL database, independently of this dashboard. The panel above shows the data of whichever OEE database you connect to; the connection parameters are stored in your browser's localStorage in plain text. If a recorder is stopped, its database simply stops receiving rows — there is no liveness indicator in the stored data. In MQTT mode, edge events that occur while the dashboard is stale, disconnected, or pointed at another line are not counted.
